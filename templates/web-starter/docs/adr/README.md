# Architecture Decision Records

One numbered Markdown file per significant, hard-to-reverse decision — the
_why_, not the _how_. Record a decision here when you jump to rung 3 or 4 of the
escalation ladder (see [`../../CODING_STANDARDS.md`](../../CODING_STANDARDS.md)),
add a build-time dependency, or make any choice a future maintainer would
otherwise have to reverse-engineer.

Suggested shape (`docs/adr/0001-short-title.md`):

```markdown
# 1. Short title

Date: YYYY-MM-DD
Status: accepted

## Context

What forces are at play?

## Decision

What we chose.

## Consequences

What becomes easier or harder as a result.
```
